# IMU 与姿态训练

- 当前状态：🔴 明显缺口 ⭐
- 最后验证日期：2026-09-07（维特智能真实技术笔试，非系统训练）
- 项目证据：爬墙机器人使用 MPU6050 做过姿态检测
- 典型问题：一面回答深度不足；笔试 E3 未稳定说明 ZYX 欧拉角在 Pitch ±90° 时的万向节死锁，E7.2 未完成恒定零偏积分误差计算
- 正确理解摘要：恒定零偏会随时间线性积累角度误差，例如 `0.1°/s × 10s = 1°`
- 学习路径：Accel/Gyro/Mag → 零偏/噪声/温漂 → 积分漂移 → Roll/Pitch/Yaw → 磁力计航向 → ZYX 欧拉角与万向节死锁 → 四元数 → 互补滤波 → Mahony/Madgwick
- 优先级边界：有实际需求后再学习 EKF，当前不把复杂 EKF 推导提升为最高优先级
- 面试表达要点：需能解释 accel 可约束 Roll/Pitch、不能单独约束 Yaw，以及陀螺零偏为何导致漂移
