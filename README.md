# 2027 嵌入式求职知识库

这是曹志东的 2027 届嵌入式实习 / 校招学习与面试知识库，用于记录真实技能画像、项目能力、JD 与公司分析、面试复盘，以及嵌入式知识训练状态。

## 使用方式

1. 首先阅读 [`00_CURRENT_STATE.md`](00_CURRENT_STATE.md) 了解当前阶段、重点和唯一下一步。
2. 只在问题需要时继续读取个人/项目画像、对应公司记录或对应训练模块。
3. 本地 Obsidian 是主要编辑源；GitHub 用于跨 Chat / Codex 按需读取和版本追踪。

仓库内容采用普通 Markdown，不依赖 Obsidian 专有插件。公开同步前必须检查个人隐私、账号凭据与不适合公开的 HR/Offer 信息。
